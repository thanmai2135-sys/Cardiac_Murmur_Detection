# Cardiac_Murmur_Detection
Cardiac Murmur Detection using Machine Learning and Audio Signal Processing

## Overview
This project detects the presence of heart murmurs from phonocardiogram (PCG) audio recordings using machine learning.

## Features
- Audio preprocessing
- Feature extraction (MFCCs, Chroma, Spectral features, etc.)
- Random Forest classifier
- Hyperparameter tuning
- Model evaluation

## Dataset
CirCor DigiScope Phonocardiogram Dataset

## Technologies
- Python
- Scikit-learn
- Librosa
- NumPy
- Pandas
- Matplotlib

## Results
Accuracy: 61.9%
Precision: 61.98%
Recall: 60..98%
